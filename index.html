Example

Ask Claude in plain English — it handles the rest:

# You say: "Create a versioned TimeSeries of hourly wind power forecasts"
# Claude generates:

import pandas as pd
from timedatamodel import TimeSeries, Frequency, DataType

df = pd.DataFrame({
    "knowledge_time": pd.date_range("2024-01-01", periods=24, freq="h", tz="UTC"),
    "valid_time":     pd.date_range("2024-01-02", periods=24, freq="h", tz="UTC"),
    "value":          wind_power_values,
})

ts = TimeSeries.from_pandas(
    df,
    frequency=Frequency.PT1H,
    name="wind_forecast",
    unit="MW",
    data_type=DataType.FORECAST,
)
# ts.shape → DataShape.VERSIONED  (inferred automatically)

About TimeDataModel

TimeDataModel is an open-source Python library by Rebase Energy for self-describing, bi-temporal time series data. Backed by Polars, designed for energy systems, forecasting, and any domain where data provenance matters.
